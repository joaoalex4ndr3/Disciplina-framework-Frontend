# Aula 3 · Calculadora React

Calculadora em React com operações aritméticas, porcentagem, inversão de sinal e limpeza do visor.

[Experimentar na Vercel](https://framework-frontend-aula3.vercel.app/).

## Executar localmente

Na pasta `Aula3`, execute `npm ci` e `npm start`. Acesse `http://localhost:3000`.
