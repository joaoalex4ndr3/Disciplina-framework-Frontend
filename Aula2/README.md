# Aula 2 · Super Calculadora Mario

Calculadora inspirada em Super Mario, desenvolvida com Next.js, React e TypeScript. Permite somar, subtrair, multiplicar, dividir e corrigir a digitação com DEL.

[Experimentar na Vercel](https://calculadora-mario.vercel.app/).

## Executar localmente

Na pasta `Aula2`, execute `npm ci` e `npm run dev`. Acesse `http://localhost:3000`.
