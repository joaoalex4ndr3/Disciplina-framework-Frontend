# 🌐 Consumo de APIs

Um dos conceitos importantes trabalhados durante o desenvolvimento frontend é a integração com APIs.

As aplicações desenvolvidas podem realizar requisições para obter informações de servidores externos e apresentar esses dados na interface.

Um fluxo básico de uma aplicação que consome uma API pode ser representado da seguinte maneira:

```text
Usuário
   │
   ▼
Interface Frontend
   │
   ▼
Requisição HTTP
   │
   ▼
API
   │
   ▼
Dados
   │
   ▼
Frontend
   │
   ▼
Interface atualizada
```

Durante os estudos são utilizados conceitos como:

* HTTP;
* GET;
* POST;
* JSON;
* Fetch API;
* Promises;
* Async/Await;
* Tratamento de erros;
* Estados de carregamento;
* Renderização de dados.

# ▶️ Executando um projeto

Como o repositório contém diferentes atividades e projetos, cada pasta pode possuir sua própria configuração.

Entre na pasta do projeto desejado:

```bash
cd nome-do-projeto
```

Instale as dependências:

```bash
npm install
```

Depois execute o projeto utilizando o script disponível no `package.json`.

Normalmente:

```bash
npm run dev
```

ou:

```bash
npm start
```

Após iniciar o servidor de desenvolvimento, o terminal informará o endereço local da aplicação.

Exemplo:

```text
http://localhost:5173
```

ou:

```text
http://localhost:3000
```

> O comando correto pode variar de acordo com o projeto.
