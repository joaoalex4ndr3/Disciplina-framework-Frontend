# Shifra  - AI Chat Assistant (Frontend Only)

🚀 A beginner-level AI chatbot UI built with **React** using **Gemini API (Google Generative AI)**. This project is developed as part of my learning journey during #100DaysOfCode to explore how to build smart assistants with modern frontend tools.

## 🔍 Features

- ✨ AI response integration using Gemini API
- ⚛️ Built with React and Vite
- 🎨 Clean UI and responsive layout
- ⚡ Basic error handling and input validation
- 🧠 Real-time typing effect and response display

## ⚙️ Tech Stack

- **React** 18.3
- **Vite** for fast development
- **@google/generative-ai** SDK
- **React Icons**


## 📌 Note

Currently this is **frontend-only**, but the concept has **a lot of future potential**. In future, it can be expanded with features like:
- Backend integration
- Chat history storage
- Authentication
- Multi-model support

Being a beginner, this project was a bit tricky. But taking **help from ChatGPT and YouTube**, I was able to pull it off! 💪  
I understood:

- How to create an interactive UI
