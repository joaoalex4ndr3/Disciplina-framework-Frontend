# Aula 4 — Projetos Frontend com APIs

## 📚 Disciplina: Framework Frontend

Nesta atividade foram pesquisados e analisados projetos Frontend disponíveis no GitHub que utilizam APIs para obter, consultar ou manipular informações.

Os projetos foram clonados e organizados neste repositório com o objetivo de analisar diferentes aplicações desenvolvidas utilizando tecnologias modernas de desenvolvimento Frontend.

---

## 🎯 Objetivo

O objetivo desta atividade é conhecer diferentes aplicações Frontend que utilizam APIs e identificar:

- Qual é a finalidade de cada projeto;
- Qual API é utilizada;
- Quais tecnologias e frameworks foram utilizados;
- Se o projeto utiliza JavaScript ou TypeScript;
- Como diferentes projetos podem consumir APIs para apresentar informações ao usuário.

# 🔎 Detalhamento dos projetos

## 1. NASA API Front

### 💡 Sobre o projeto

O NASA API Front é uma aplicação Frontend que utiliza dados disponibilizados pela NASA através de uma API.

A aplicação demonstra como uma interface desenvolvida em React pode realizar requisições para uma API externa e apresentar os dados obtidos de maneira visual para o usuário.

### 🔌 API

**NASA API**

A API disponibiliza informações e conteúdos relacionados aos projetos e dados da NASA.

### 🛠️ Tecnologias

- React
- JavaScript
- Vite

### 📌 Conceitos observados

- Componentização com React;
- Consumo de API;
- Requisições HTTP;
- Exibição dinâmica de dados.

# 📊 Comparação das tecnologias

Durante a análise dos projetos, foi possível observar a utilização de diferentes tecnologias e ferramentas no desenvolvimento Frontend.

| Tecnologia | Projetos que utilizam |
|---|---|
| React | Todos os projetos analisados |
| JavaScript | NASA API Front, ALTER-EGO, Virtual Assistant, News API React App, Anime API, Rest Countries React e Store App Frontend |
| TypeScript | Gamelisting, Game Hub e CEO Dog Code Challenge |

# 📌 Conclusão

A análise dos projetos permitiu observar diferentes formas de utilização de APIs em aplicações Frontend.

Mesmo utilizando o mesmo framework, como o React, cada projeto possui uma finalidade diferente. Foram encontrados exemplos relacionados a jogos, notícias, países, animes, animais, inteligência artificial e comércio eletrônico.

Também foi possível observar a diferença entre projetos desenvolvidos utilizando **JavaScript** e **TypeScript**, além da utilização de diferentes ferramentas para estilização, roteamento, gerenciamento de estado, animações e realização de requisições HTTP.

O uso de APIs permite que aplicações Frontend trabalhem com informações externas e dinâmicas, tornando as interfaces mais completas e interativas.
