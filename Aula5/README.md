# Aula 5 · Aplicativo de notas

A atividade integra uma interface React com uma API REST em Node.js e Express. O aplicativo permite listar, criar, editar e excluir notas.

| Componente | Código | Acesso |
| --- | --- | --- |
| Frontend React | [Pasta do frontend](Express-Frontend-aula05/) | [Aplicativo na Vercel](https://expressfrontendaula5.vercel.app/) |
| Backend Express | [Pasta do backend](Express-backend-aula05/) | [Consulta de notas no Render](https://express-backend-aula05-134x.onrender.com/api/notes) |

O servidor Express utiliza `data.json` para gravar notas. A interface publicada consulta o serviço do Render. Para executar os componentes localmente, consulte seus READMEs.
